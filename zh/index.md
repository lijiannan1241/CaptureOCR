        <h2 id="faq-title">评估者常问的问题</h2>
        <p class="section-lede">简短直接的回答。更多问题请看 <a href="https://github.com/lijiannan1241/CaptureOCR/issues">Issue 列表</a>。</p>

      <div class="faq-list">
        <details class="faq-item" open="">
          <summary>CaptureOCR 免费吗？</summary>
          <div class="faq-answer">
            <p>不免费。CaptureOCR 在微软商店一次性购买 <strong>¥21</strong> (约 $2.99)。无订阅制。各地定价和试用由商店决定。</p>
          </div>
        </details>

        <details class="faq-item">
          <summary>支持离线使用吗？</summary>
          <div class="faq-answer">
            <p>支持。tiny 模型随 MSIX 包内置，安装即可完全离线使用。精准模式 (small) 首次下载 (~30 MB) 后同样离线运行。全程无云端 OCR API 调用。</p>
          </div>
        </details>

        <details class="faq-item">
          <summary>支持哪些语言？</summary>
          <div class="faq-answer">
            <p>small 档覆盖 50 种语言，含中文、日文、英文及 46 种拉丁系语言。tiny 档覆盖 49 种，不含日文 —— 需识别日文请切到精准模式。</p>
          </div>
        </details>

        <details class="faq-item">
          <summary>与 Windows 截图工具 / PowerToys 有何不同？</summary>
          <div class="faq-answer">
            <p>内置工具一次只提取一个区域、返回纯文本流。CaptureOCR 一次会话捕获多区域、自动编号、导出带坐标和置信度的 Markdown/CSV 表格。且在同一窗口集成标注、美化与 OCR，美化后的图片仍可提取文本。</p>
          </div>
        </details>

        <details class="faq-item">
          <summary>支持滚动截图吗？</summary>
          <div class="faq-answer">
            <p>v1.0 作为尽力而为功能支持。采用行签名拼接 (32 桶) + 吸顶栏跳过 + 自适应滚轮步长。稳定滚动场景效果最好；虚拟列表、懒加载列表可能失败。区域捕获是可靠的后备方案。</p>
          </div>
        </details>

        <details class="faq-item">
          <summary>我的截图会上传吗？</summary>
          <div class="faq-answer">
            <p>不会。截图与识别文本留在本地。设置和会话文件本地存储。仅可选的精准模型下载和微软商店授权用到网络。支付由微软处理；我们从未见过您的卡号。</p>
          </div>
        </details>

        <details class="faq-item">
          <summary>支持哪些导出格式？</summary>
          <div class="faq-answer">
            <p><strong>Markdown 表格</strong> (区域索引、坐标、行号、置信度、文本)，<strong>CSV</strong> 含 UTF-8 BOM (session_id、索引、x,y,w,h、行索引、置信度、文本、模式、耗时_ms、模型哈希)，<strong>TXT</strong> (纯文本块)，以及 <strong>.snipx 会话包</strong> (ZIP 含原图、Markdown、CSV、完整 JSON 含归一化框)。</p>
          </div>
        </details>

        <details class="faq-item">
          <summary>能做表格提取吗？</summary>
          <div class="faq-answer">
            <p>不能直接提取表格结构。CaptureOCR 导出<em>行级行</em>而非单元格级表格重建。捕获的表格变为带区域坐标的文本行。单元格合并和列推断需要版面分析 —— 那是另一个问题。许多用户在 Excel 中透视 CSV 来处理表格。</p>
          </div>
        </details>
      </div>
